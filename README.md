# CCIRS
Campus complaint and issue reporting system

## Project Description

CCIRS (Campus Complaint & Issue Reporting System) is a web-based system designed to help students report campus-related complaints and issues and allow authorized administrators to manage and track those complaints.

The system aims to provide a simple, organized, and secure way to submit, track, and manage campus complaints.

## Objectives

- Provide students with an easy way to submit complaints.
- Allow students to track their submitted complaints.
- Allow administrators to view and manage complaints.
- Maintain secure user authentication and authorization.
- Protect users' data and prevent unauthorized access.

## Main Features

- Student registration and login
- Complaint submission
- Complaint tracking
- Admin dashboard
- Complaint status management
- Role-based access control
- Secure authentication
- Security testing and vulnerability assessment
- AI-based complaint classification

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python / FastAPI
- Database: SQLite
- AI/ML: Python-based model
- Version Control: Git & GitHub

## Security

Security is an important part of CCIRS. The project will include security practices such as:

- Secure password storage
- Input validation
- Protection against SQL Injection and XSS
- Authentication and authorization
- Role-Based Access Control (RBAC)
- IDOR testing and prevention
- OWASP Top 10 security review
- Secure handling of application secrets
- Security testing before deployment
